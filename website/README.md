# Add Call product page

A single page (`index.html`) with its images (`img/`). No build step: upload the folder as it is, keeping `img/` next to `index.html`.

The images in `img/t-*.webp` are crops of the store images in `design/store` (the device only, without the headline). If those change, re-make the crops.

Links on the page:
- Web app: `https://call.adddots.com/`
- Google Play: `https://play.google.com/store/apps/details?id=com.adddots.call` (works once the app is live on Play)
- Android APK: `https://adddots.com/adddotsmain/addcall/add-call.apk`
- Microsoft Store: the two Windows buttons are placeholders (`href="#"`, marked with a comment). Put in `https://apps.microsoft.com/detail/<Store ID>` once the app is listed.
